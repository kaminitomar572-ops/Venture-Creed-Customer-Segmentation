# Venture-Creed-Customer-Segmentation
Customer segmentation and clustering analysis using Python and K-Means.


## Project Overview

Analyzed customer purchasing behavior to identify distinct customer
segments and develop segment-specific business strategies.

## Objective

- Identify meaningful customer segments
- Analyze purchasing behavior across segments
- Determine key characteristics of each cluster
- Translate analytical findings into business recommendations

## Tools & Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Methodology

1. Exploratory Data Analysis
2. Data Quality Assessment
3. Feature Selection
4. Missing Value Treatment
5. Outlier Detection using Isolation Forest
6. Feature Standardization
7. K-Means Clustering
8. Cluster Evaluation using Silhouette Score
9. Cluster Profiling
10. Business Recommendations

## Key Findings

Identified 3 distinct customer segments based on purchasing
characteristics, revenue, profitability, market potential and
purchase propensity.

### Business Insights

- Cluster 1: Core/Stable Customer Base
- Cluster 2: High-Value/Growth Customers
- Cluster 3: Lower-Value Customers requiring targeted re-engagement

## Recommendations

- Focus retention strategies on core customers.
- Prioritize high-value customers for upselling and cross-selling.
- Develop targeted re-engagement strategies for lower-value customers.
